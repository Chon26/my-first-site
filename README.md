# my-first-site

หน้าเว็บพอร์ตโฟลิโอส่วนตัว สร้างด้วย HTML/CSS ล้วน ไม่มี framework หรือ build tool

## โครงสร้างหน้า

- **Header** — รูปโปรไฟล์, ชื่อ, ตำแหน่ง/สายงาน
- **เกี่ยวกับฉัน** — แนะนำตัวสั้นๆ
- **ทักษะ** — รายการทักษะแบบ tag
- **ผลงานที่เคยทำ** — ตารางแสดงชื่องาน, รายละเอียด, เทคโนโลยี, ปี, ลิงก์
- **ติดต่อ** — อีเมล, LinkedIn, GitHub

## วิธีใช้งาน

1. เปิด [`index.html`](index.html) เพื่อดูตัวอย่างหน้าเว็บ
2. แก้ไข placeholder ที่อยู่ในวงเล็บ `[...]` ให้เป็นข้อมูลจริงของตัวเอง เช่น ชื่อ, ทักษะ, ผลงาน, ลิงก์ติดต่อ
3. เปลี่ยนรูปโปรไฟล์จาก placeholder เป็นรูปจริงของคุณ

## Deploy

โปรเจกต์นี้เป็น static site สามารถ deploy ผ่าน [GitHub Pages](https://pages.github.com/) ได้โดยตรง ไม่ต้องมีขั้นตอน build
